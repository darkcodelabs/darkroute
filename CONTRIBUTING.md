# Contributing

The complete contributor guide is
[`docs/public/CONTRIBUTING.md`](docs/public/CONTRIBUTING.md). It covers setup,
gates, privacy invariants, design-gap records, tests, commit conventions, and
the documentation that must change with each behavior.

Before opening a pull request:

1. Install with `./installer.sh`.
2. Create a focused branch; do not commit directly to `main`.
3. Run `pnpm typecheck`, `pnpm lint`, and `pnpm test`.
4. Use a Conventional Commit subject.

Community conduct is governed by
[`docs/CODE_OF_CONDUCT.md`](docs/CODE_OF_CONDUCT.md). Security and privacy
reports follow [`.github/SECURITY.md`](.github/SECURITY.md), not a public issue.
