# Moved

The notices archive lives at the **repository root**, not here:

**[`/transparency/`](../../../transparency/README.md)**

It was moved there deliberately. An archive of legal demands is one of the first
things a hostile reader looks for, and `github/dmca` — the convention this
archive copies — is a top-level repository for the same reason. Three
directories deep inside `docs/` is where a thing goes when nobody is meant to
find it.

The **policy** that governs the archive — what is published, what is redacted,
on what timeline, and why there is no general warrant canary — stays here as
[`../TRANSPARENCY.md`](../TRANSPARENCY.md), because it is a document a reader
reads, not a record.

This stub exists only so that older links resolve. It holds no notices and never
will.
